ОПИСАНИЕ
--------
Программа автоматически извлекает структуру сборки из КОМПАС-3D
и создаёт сводную ведомость в форматах Excel (.xlsx), Word (.docx)
и PDF (.pdf).

Возможности:
- Подключение к КОМПАС-3D v24 через COM
- Обход дерева сборки с извлечением свойств деталей
- Чтение позиций из спецификаций (.spw файлы)
- Определение гнущихся деталей (листовых)
- Фильтрация материалов по умолчанию
- Форматирование по ГОСТ (группировка, цвета, шрифты)
- Генерация Excel, Word и PDF одновременно
- Выбор форматов экспорта (Excel / Word / PDF)
- Калькулятор стоимости (материалы + трудозатраты)
- Шаблоны для настройки формата выходных файлов
- Перетаскивание файлов (drag & drop) в окно программы
- Список последних файлов для быстрого доступа
- Сворачиваемые секции (лог, последние файлы)

СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
- Windows 10/11 (x64)
- КОМПАС-3D v24 (установлен и запущен)

УСТАНОВКА НЕ ТРЕБУЕТСЯ
----------------------
Программа является автономным приложением.
Python и дополнительные библиотеки НЕ нужны.

ЗАПУСК
------
1. Распакуйте архив в любую папку
2. Убедитесь, что КОМПАС-3D v24 запущен
3. Откройте сборку (.a3d файл) в КОМПАС-3D
4. Запустите Svodnik.exe

РАБОТА С ПРОГРАММОЙ
-------------------
1. Выберите файл сборки одним из способов:
   - Нажмите "Обзор..." и выберите файл (.a3d / .a3t)
   - Перетащите файл сборки в окно программы (drag & drop)
2. Выберите нужные форматы (Excel / Word / PDF)
3. Нажмите "ЭКСПОРТ"
4. Результат сохранится в папке рядом с файлом сборки:
   - <имя>_сводная_ведомость.xlsx
   - <имя>_сводная_ведомость.docx
   - <имя>_сводная_ведомость.pdf

МЕНЮ
----
Вид:
  - Последние файлы — список последних сборок для быстрого доступа
  - Лог — журнал операций

Настройки:
  - Ввести лицензию — активация лицензионного ключа
  - Мой ID компьютера — получить ID для получения лицензии
  - Шаблоны — настройка формата выходных файлов
  - Цены и калькулятор — редактирование цен на материалы
  - Выход

Справка:
  - О программе — информация о версии

ШАБЛОНЫ
-------
Шаблоны позволяют настроить формат выходных файлов.

Меню "Настройки → Шаблоны...":
  - Выберите шаблон из списка и нажмите "Применить"
  - Создайте новый шаблон кнопкой "Создать"
  - Отредактируйте существующий кнопкой "Редактировать"

Структура шаблона:

  "name": "Название шаблона",
  "excel": {
    "title": "Заголовок таблицы",
    "columns": [
      {"key": "position", "header": "Позиция", "width": 8},
      {"key": "marking", "header": "Обозначение", "width": 25},
      {"key": "name", "header": "Наименование", "width": 40},
      {"key": "quantity", "header": "Кол-во", "width": 12},
      {"key": "mass_kg", "header": "Масса, кг", "width": 12},
      {"key": "total_mass", "header": "Масса общая", "width": 12},
      {"key": "material", "header": "Материал", "width": 25},
      {"key": "bending", "header": "Гибка", "width": 8}
    ],
    "header_color": "2F5496",
    "assembly_color": "D6E4F0"
  },
  "word": {
    "title": "Заголовок",
    "columns": [
      {"key": "position", "header": "Поз."},
      {"key": "marking", "header": "Обозначение"},
      {"key": "name", "header": "Наименование"},

Пользовательские шаблоны сохраняются в папке ~/.svodnik_templates/

КАЛЬКУЛЯТОР СТОИМОСТИ
---------------------
Меню "Настройки → Цены и калькулятор..." позволяет задать цены
на материалы и стоимость работ.

Структура файла цен:
{
  "materials": {
    "сталь 10": 85.0,
    "сталь 20": 90.0,
    "алюминий": 250.0
  },
  "default_material_price": 100.0,
  "labor": {
    "cutting_per_kg": 15.0,
    "bending_per_kg": 25.0,
    "welding_per_kg": 30.0,
    "assembly_per_kg": 20.0
  }
}

materials — цена за 1 кг по названию материала (подстрока).
default_material_price — цена для материалов, не найденных в списке.
labor — стоимость работ за 1 кг. bending применяется только к гнущимся.

Для расчёта стоимости поставьте галочку "Стоимость" перед экспортом.
В Excel добавятся столбцы: Стоимость мат., Стоимость работ, Итого.

ЛИЦЕНЗИРОВАНИЕ
--------------
Программа работает в пробном режиме:
- 5 экспортов
- 14 дней

Для получения полной лицензии:
1. В меню "Настройки" нажмите "Мой ID компьютера"
2. Скопируйте ID компьютера
3. Отправьте его распространителю (djonros2012@ya.ru)
4. Получите лицензионный ключ
5. В меню "Настройки" нажмите "Ввести лицензию" и вставьте ключ

Формат ключа: KEY-XXXXXXXXXXXX-YYYY-MM-DD

ОШИБКИ И РЕШЕНИЯ
-----------------
Ошибка "Не удалось подключиться к КОМПАС-3D":
  Убедитесь, что КОМПАС-3D v24 запущен и сборка открыта.

Ошибка "TopPart не найден":
  Файл должен быть сборкой (.a3d), а не деталью (.m3d).

Проблемы с производительностью:
  На больших сборках (1000+ деталей) экспорт может занять
  несколько минут. Это нормально.
