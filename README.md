# Экспорт спецификаций из КОМПАС-3D v24

## Описание

Программа для автоматического создания сводных ведомостей (спецификаций) из сборок КОМПАС-3D v24. Результат сохраняется в форматах Excel и Word.

## Возможности

- Извлечение полной структуры сборки из КОМПАС-3D
- Автоматическое чтение позиций из файлов спецификаций (.spw)
- Автоперестройка спецификаций перед чтением
- Группировка по сборкам с вложенностью
- Автоматическая отметка гнутых деталей (столбец "Гибка"): листовые операции сгиба, гибы по геометрии у деталей из листа, гнутые трубы
- Редактор строк перед экспортом (правка, добавление и удаление позиций)
- Столбец "Длина сортамента": длина детали из проката в мм определяется автоматически, можно поправить в редакторе строк
- Фильтр материала по умолчанию (Сталь 10 и т.д.) у сборок
- Закрытие окон КОМПАС после работы
- Сохранение файлов в папку сборки
- Проверка обновлений: программа сама находит новую версию, показывает список изменений и обновляется одной кнопкой

### 1.6.6

- Если у сборки или подсборки нет своей спецификации (.spw), она создается автоматически по модели и сохраняется в папку "Генерированные спецификации" рядом со сборкой как "<обозначение> СП.spw". Позиции и количество берутся из нее, со сверкой количества с моделью; в конце экспорта показывается, какие спецификации созданы
- Сборки при этом не меняются: спецификация к модели не привязывается
- Если у деталей сборки нет объектов спецификации и созданная спецификация пустая, это показывается в списке проблем
- Вопросы КОМПАС при чтении спецификаций ("Перестроить спецификацию?") больше не останавливают экспорт: на время чтения на них автоматически отвечается "Нет", перестроение программа делает сама. Прочитанные спецификации закрываются без сохранения

### 1.6.5

- "Длина сортамента" заполняется автоматически для деталей из проката (профиль, труба, уголок, швеллер, двутавр, круг, квадрат, полоса и т.п.). Прокат определяется по материалу, а если материал не задан или задан по умолчанию, по наименованию; детали из листа не считаются
- Длина берется из "L = ... мм" в наименовании или имени файла (так ее пишет библиотека металлоконструкций), иначе из габарита детали в ее собственной системе координат (поворот детали в сборке не мешает). Если деталь построена наискосок, берется самое длинное прямое ребро
- Если длину определить не удалось, это показывается в списке проблем в конце экспорта. Значение по-прежнему можно поправить в редакторе строк

### 1.6.4

- Гибка определяется автоматически по самой детали, а не только по разогнутому листовому телу. Деталь отмечается, если:
  - в ней есть листовые операции сгиба (сгиб, сгиб по линии, по эскизу, буртик, подсечка, обечайка) или листовое тело разогнуто;
  - она из листа или полосы и в ней есть пара соосных цилиндрических граней, у которых радиусы отличаются на толщину листа (внутренний и наружный радиус гиба), так находятся гибы у деталей, построенных обычным выдавливанием. Скругления углов контура и отверстия гибами не считаются;
  - она из трубы или круга и в ней есть тороидальные грани (гнутая труба).
- Сортовой прокат (швеллер, уголок, профиль) по радиусам не проверяется, чтобы не путать его с гибкой. Названия деталей не используются. Ручная отметка в редакторе строк по-прежнему работает

## Использование

### Через командную строку

```bash
# Обработка активного документа в КОМПАС
python kompas_export_final.py

# Обработка указанного файла
python kompas_export_final.py "C:\path\to\assembly.a3d"
```

### Через Python

```python
from kompas_export_final import KompasExportFinal

exporter = KompasExportFinal()
exporter.run("C:\\path\\to\\assembly.a3d")
```

## Особенности

### Чтение позиций из спецификаций

Программа автоматически ищет и читает файлы спецификаций (.spw) в папке `Рабочка` (родительская папка относительно `Модель`). 

Если спецификация требует перестройки, программа выполняет её автоматически.

### Фильтр материала

У сборок автоматически удаляется материал по умолчанию (Сталь 10, Сталь 20 и т.д.), так как он не несет информации о конкретном материале деталей.

### Отметка деталей с разверткой

Столбец "Гибка" отмечается "X" только для деталей, у которых в КОМПАС-3D
включен статус развертки (листовое тело разогнуто, `ISheetMetalBody.Straighten`).

Если у детали нет листовых тел (например, она построена выдавливанием),
столбец остается пустым — гибку можно проставить вручную в редакторе строк,
отметив нужные детали галочками.

Для проверки того, какие тела и статусы видит API, запустите
диагностический скрипт (при открытой детали в КОМПАС):

```bash
python tools/diag_bend.py [C:\path\to\detail.m3d]
```

### Закрытие окон

Программа автоматически закрывает все окна КОМПАС, которые были открыты в процессе работы.

## Решение проблем

### Ошибка "Invalid class string"

Убедитесь, что КОМПАС-3D v24 установлен. Программа использует `Kompas.Application.7`.

### Ошибка "Permission denied"

Закройте файл Excel, если он открыт.

### Медленная работа

Чтение спецификаций (.spw) занимает время. Для сборок с большим количеством подсборок это может занять несколько минут.
